# Code of Conduct

love follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good faith and criticize code, not people. Harassment, insults and discriminatory language aren't accepted in issues, pull requests, discussions or anywhere else you represent the project.

## Reporting

If something happens, write to the maintainer, [Thiago Dutra](https://github.com/thdtr), privately. Reports are kept confidential. Maintainers may remove content, give warnings or ban people, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
